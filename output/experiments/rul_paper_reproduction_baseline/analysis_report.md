# 원본 4초 센서 기반 3출력 RUL 개발 기준 실험

기존 24h XGBoost Model 1은 열거나 학습·변경하지 않았다. 기존 0~6h 조건부 GRU와 달리 실제 TTF로 입력 창을 미리 고르지 않았다. 창당 2,000개 실제 `FIXTURESHUTTERPOSITION==1` 관측치를 사용했고 인접 창은 500개를 공유한다. 창 시작·끝과 유형별 정답 사건은 같은 시간 분할에 있어야 한다. 한 유형의 창이 그 유형의 직전 고장 이전까지 거슬러 올라가면 해당 head를 마스킹한다. 중복 제거된 1,211개 원본 fault 사건 중 예약 구간을 제외한 잠재 사건 644건이 2,000개 작동 관측치를 가질 수 있었고, 실제 창 구성·경계·정답 마스크 뒤 학습 455건, 검증 148건의 유형별 사건이 남았다. 이 수치는 이전의 `next-any-fault` 0~6h 학습 304/검증 116건과 **표본 정의가 다르므로 성능 비교 수치가 아니다**.

## 입력·전처리

- 원본 숫자 센서 9개: `IONGAUGEPRESSURE`, `ETCHBEAMVOLTAGE`, `ETCHBEAMCURRENT`, `ETCHSUPPRESSORVOLTAGE`, `ETCHSUPPRESSORCURRENT`, `FLOWCOOLFLOWRATE`, `FLOWCOOLPRESSURE`, `ETCHGASCHANNEL1READBACK`, `ETCHPBNGASREADBACK`.
- 모델은 2,000개 창에서 20번째마다 하나를 취한 100-step sequence를 사용한다. 이는 작은 기준 모델을 위한 **추가 축소**로, 논문 1의 d1=2와 d2=10 T2V 구현과 동일하지 않다. 85개 가공 feature, TTF, 고장 시각, Tool ID, 절대시간은 입력하지 않았다.
- Train에서만 센서별 median/IQR을 계산해 스케일링했다. 센서 결측 창은 가짜값으로 채우지 않고 제외했다. 90초 초과 공백은 폐기 조건으로 쓰지 않았다. 실제 경과시간, 최대 공백, 세션 전환은 창 metadata에 기록했다. 19,436개 사용 창의 99.6%에 >90초 공백이 있었고, 최댓값의 중앙값은 3,768초, 창 전체 실제 경과시간 중앙값은 약 5.99시간이었다. 현재 GRU는 이 시간 metadata를 입력받지 않아 불규칙 시간 간격의 의미를 직접 학습할 수 없다.
- 유형별 다음 같은 유형 고장까지의 **실제 시계시간**을 target으로 생성했다. 분할 안에 다음 고장이 없으면 검열/미확인으로 표시하고 그 head의 loss와 지표에서 제외했다. 그 값을 임의의 큰 RUL로 대체하지 않았다. 학습 target은 `log1p(hours)`, 추론 출력은 `expm1`으로 복원했다. 유효 head별 평균 제곱 오차를 계산한 뒤 세 유형을 동일하게 평균하여 저압 행 수만으로 loss가 결정되지 않도록 했다.
- 이미 고정된 설비별 과거 Train/후속 Validation과 24h purge를 사용했다. 예약 Test는 학습·검증·선택에서 사용하지 않았다. Fold는 검증 사건의 고장 시각 순으로 나눠 같은 사건 창을 한 fold에 둔 안정성 점검이다. 독립 Test가 아니다.

## 사건·설비·시간 편차

- 유효 target 사건: Train 저압 309/고압 105/누출 41, Validation 저압 108/고압 30/누출 10. 유형별 불균형이 크고 누출의 추정은 특히 불확실하다.
- GRU 시간순 fold별 행 MAE: 저압 293.55/374.47/289.94h; 고압 380.36/326.02/347.42h; 누출 473.00/476.68/713.35h. 누출은 마지막 fold가 악화됐으며 fold당 사건은 3/3/4건에 불과하다.
- 설비별 표본과 MAE는 `tool_metrics.csv`에 저장했다. 1건짜리 설비의 값으로 일반화하지 않는다.
- 전체 검증 확률 생성 후 **사후 진단**으로만 실제 TTF≤24h 구간을 확인했다. GRU 유형별 MAE는 저압 301.64h/고압 437.79h/누출 915.42h였고, 24h 내 사건 수도 작다. 이 구간을 입력 선택·학습·모델 선택에 사용하지 않았다.

## 채택 판단

새 모델과 Train-only scaler는 `output/models/rul_paper_multioutput_gru.pt`에, 재현 설정은 `experiment_config.json`에 저장했다. Model 1 연결 평가의 사전 조건은 **24h 위험 설비에 의미 있는 RUL 개선**이었다. 이번 GRU는 전체 장기 TTF에서는 Dummy보다 낮은 평균 오차를 보였지만, 24h 임박 구간에서 수백 시간 오차이고 Tree보다 사건 동일가중 성능도 낮다. 따라서 Model 1 연결로 모델을 선택하거나 대시보드 예상시간으로 표시하지 않는다. 연결 coverage/MAE는 이번 실험에서 산출하지 않았다고 명시한다.

다음 한 실험은 모델 구조 튜닝 전에 **Train으로만 정한 열화 시작/상한 규칙과 실제 경과시간 입력을 추가한 데이터 구성**이 같은 사건·검증 집합에서 Dummy를 이기는지 확인하는 것이다. 이는 이번 결과를 소급해 바꾸지 않는다.
