# TTF 0~6시간 조건부 회귀 검증

실제 1분 관측 자료에서 유형별 다음 고장까지 **실제 0~6시간이 남은 행**을 골랐다. TTF는 정답과 분석 대상 선정에만 사용했다. 고압 feature는 이온 게이지 압력 현재값·과거 실제 10분 표준편차, 누출은 FlowCool 압력 현재값·과거 실제 30분 평균, 저압은 FlowCool 압력·유량 현재값과 각각의 과거 실제 30분 평균이다. 기존 준비 데이터의 `mean_30m`은 30개 관측 행 기준이므로 사용하지 않고, 경과시간 기준으로 재계산했다. 가동 중단으로 나뉜 세션을 넘어서 이력을 연결하지 않았다.

유형별 고장 사건 시각을 시간순 약 70/30으로 분할하고 경계 양쪽 6시간을 제외했다. Train·Validation에 같은 사건이 없고, Train 마지막 관측이 Validation 첫 관측보다 이르다. 기존 HGB-log 설정과 기존 XGBoost 회귀 설정을 사용했으며 하이퍼파라미터 탐색은 하지 않았다.

누출 XGBoost는 Dummy 대비 MAE 약 10.15분·RMSE 약 7.14분 개선됐지만 **검증 고장이 단 2건**이다. 우연한 사건 조합일 가능성을 배제할 수 없다. 고압 HGB-log는 MAE만 6.42분 개선되고 RMSE·R²는 악화됐다. 저압에서는 두 모델 모두 Dummy 대비 MAE·RMSE·R²가 악화됐다.

실제 0~2/2~4/4~6시간에 대한 XGBoost 평균 예측은 고압 약 155/202/176분, 누출 약 109/160/168분, 저압 약 172/177/179분이었다. 특히 고압·저압에서 3개 시간 구간을 제대로 분리하지 못한다. 사건별 오차도 `event_metrics.csv`에 있으며, 한 사건이 반복 관측 행을 많이 제공해 행 단위 지표를 좌우할 수 있다.

**운영 제약:** 실제 TTF를 알아야 0~6시간 대상을 고를 수 있다. 운영 중에는 이 조건을 알 수 없으므로 이 지표는 조건부 회귀만 평가한다. 앞단 위험 모델과 연결한 end-to-end 예상 TTF 성능이 아니다. 이미 여러 번 살펴본 검증 구간을 재사용했고 독립 최종 Test는 열지 않았다. 어느 유형도 아직 대시보드의 연속 예상 TTF로 쓰기 어렵다. 누출은 더 많은 이후 시점의 독립 고장으로 확인할 가치가 있고, 저압은 별도 문제 정의가 필요하다.
