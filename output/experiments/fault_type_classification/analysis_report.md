# 고장 유형 진단 모델 가능성 점검

20대 설비의 전체 fault 기록 1,236행에서 같은 Tool·유형·시각 중복 25행을 제거해 고유 사건 **1,211건**을 확인했다(저압 741, 고압 333, 누출 137). 이 중 4건은 해당 설비의 첫 센서 관측보다 앞이다. 직전 고장 이후 실제 고장 직전까지 센서 기록이 있는 사건은 1,047건이다. 각 사건의 과거 1·6·12·24시간 안에 센서가 **한 번 이상** 기록된 사건은 각각 717·914·959·989건이다. 이는 해당 시간 전체가 연속 관측됐다는 뜻이 아니다. 세부 설비·유형 건수는 `fault_type_by_tool.csv`, 사건별 가용성은 `event_sensor_coverage.csv`에 있다.

분류 baseline은 사건당 고장 **6시간 전 ±1시간**에 가장 가까운 실제 1분 관측 한 행만 사용했다. 앞선 같은 설비의 fault보다 뒤에 있어야 하고, 그 시점까지의 센서만 feature로 계산했다. 입력은 FlowCool 압력·유량·이온 게이지 압력 현재값, FlowCool 압력·유량의 과거 실제 30분 평균, 이온 게이지 압력의 과거 실제 10분 표준편차 **6개**다. fault 이름·실제 TTF·fault 이후 센서·미래 센서는 입력에 없다. 기존 Model A의 설비별 시간순 Train/Validation과 24시간 이상 경계 공백을 유지하고, 같은 사건을 두 쪽에 넣지 않았다. 뒤에 남긴 Test 센서는 읽지 않았다.

| 구분 | 전체 모델 표본 | 저압 | 고압 | 누출 |
|---|---:|---:|---:|---:|
| Train 사건 | 364 | 288 | 50 | 26 |
| Validation 사건 | 121 | 103 | 13 | 5 |

| 모델 | Macro F1 | Balanced Accuracy | Accuracy |
|---|---:|---:|---:|
| 다수 유형만 예측 | 0.307 | 0.333 | 0.851 |
| HGB, 균형 가중치 | **0.485** | **0.493** | 0.810 |

HGB의 유형별 Precision / Recall / F1은 저압 0.911 / **0.893** / 0.902, 고압 0.417 / **0.385** / 0.400, 누출 0.125 / **0.200** / 0.154다. 저압만 출력하는 모델보다는 Macro F1이 높지만 누출 5건 중 1건, 고압 13건 중 5건만 찾았다. 저압을 고압으로 7건, 고압을 저압으로 5건, 누출을 저압으로 4건 혼동했다. 누출 표본이 매우 적어 유형별 확률의 신뢰성과 보정 상태를 판단할 수 없다.

**핵심 제한:** 고장 6시간 전이라는 시점은 실제 미래 고장 시각을 알아야 선택할 수 있다. 운영 시점의 Model 1 경보가 언제 발생할지는 다르며, 이 결과는 Model 1이 경보를 낸 행에 대해 Model 2가 유형을 맞히는 *연결 시스템 성능*이 아니다. 운영에서는 Model 1이 위험 신호를 내지 않으면 Model 2 결과를 표시하지 않는 구조가 맞다. 현재 raw 확률을 점검 우선순위의 확정 확률로 사용해서는 안 된다.

따라서 유형 진단은 두 번째 모델의 **연구 후보로 남길 가치**가 있지만 최종 운영 모델로 선정하기에는 이르다. 후속 검증은 실제 Model 1 경보 시각만 골라 사건별 유형 분류와 세 유형의 확률 보정·오경보를 시간상 독립된 기간에서 측정해야 한다. 현재 Model 1은 수정하지 않았다.
