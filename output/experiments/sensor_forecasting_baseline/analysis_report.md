# FlowCool 미래 센서값 예측 기준 실험

기존 24시간 XGBoost 고장 분류 모델은 수정하지 않았다. 20대의 실제 1분 관측 자료에서 시계시간 5분마다 예측 시작점을 선택하고, 30/60분 뒤 또는 최대 60초 늦은 실제 관측이 **동일한 연속 가동 구간**에 있을 때만 정답으로 사용했다. 정지 공백은 채우지 않았다. 기존 Model A 시간순 Train/Validation 경계를 쓰며 미래 정답도 해당 경계를 넘지 못하게 했다. 뒤에 남긴 Test 센서행은 읽지 않았다.

입력은 현재 두 센서값, 실제 시계시간 기준 과거 1/5/10분 lag, 5/10/30분 평균·표준편차, 10분 기울기, 현재 stage 및 Tool이다. TTF·고장 시각·미래 센서값은 feature가 아니다. 고장 전 24시간 표지는 **평가 구간 분리용으로만** 사용했다. 튜닝 없이 고정 설정의 XGBoost 회귀와 현재값 유지 예측을 같은 검증 행에서 비교했다. MAE/RMSE는 처리 데이터의 센서 척도이며 물리 단위로 해석하지 않는다.

| 센서 | 미래 시점 | 검증 행 | 현재값 유지 MAE / RMSE / R² | XGBoost MAE / RMSE / R² |
|---|---:|---:|---|---|
| 압력 | 30분 | 42,610 | 0.382 / 1.005 / 0.744 | 0.390 / 0.871 / 0.808 |
| 압력 | 60분 | 22,344 | 0.570 / 1.475 / 0.694 | 0.757 / 1.713 / 0.587 |
| 유량 | 30분 | 42,610 | 0.512 / 1.045 / 0.195 | 0.432 / 0.740 / 0.596 |
| 유량 | 60분 | 22,344 | 0.655 / 1.206 / 0.145 | 0.515 / 0.860 / 0.565 |

유량 전체 행의 값 예측은 나아졌지만 설비별 MAE 개선은 30·60분 모두 **5/20대**에서만 확인됐다. 압력은 30분 RMSE만 개선되고 MAE가 나빠졌으며, 60분은 모든 핵심 지표가 악화됐다.

| 센서 | 미래 시점 | 고장 전 24h 행 | 현재값 유지 MAE | XGBoost MAE |
|---|---:|---:|---:|---:|
| 압력 | 30분 | 5,023 | 0.430 | 0.616 |
| 압력 | 60분 | 2,850 | 0.646 | 1.491 |
| 유량 | 30분 | 5,023 | 0.546 | 0.594 |
| 유량 | 60분 | 2,850 | 0.601 | 0.653 |

고장 전 구간은 네 경우 모두 MAE가 악화됐다. 전체 구간의 높은 R²를 고장 직전 추세 예측력이라고 해석할 수 없다.

상승/안정/하락은 Train의 미래 변화량 표준편차 10%를 안정 허용폭으로 정했다. XGBoost 전체 방향 정확도는 압력 30·60분 **51.1%·51.0%**, 유량 **49.6%·52.9%**이고, 현재값 유지의 **62.4%·53.6%**, **66.3%·58.4%**보다 낮았다. 실제 변하는 행만 보면 XGBoost 방향 일치도는 78~95%지만 전체 행의 76~82%에서 변화를 예측했고, 실제 안정 행의 68~73%에도 불필요한 변화를 예측했다. 예측한 변화의 실제 방향 정밀도는 39~46%에 그쳤다. FlowCool 유량의 어느 방향이 악화인지는 유형·운전 상태에 따라 달라 이번에 정의하지 않았다.

현재로서는 유량 **값 예측만 연구 후보**로 남길 수 있다. 고장 전 정확도와 설비별 일관성, 변화 방향의 오경보가 개선되기 전에는 두 번째 운영 모델이나 관리자 악화 추세 표시로 채택하기 어렵다. 기존 검증 구간을 재사용했으므로 독립 최종 성능이 아니며, 30·60분 뒤 실제 관측이 없는 정지 구간은 평가 대상에서 제외됐다.
