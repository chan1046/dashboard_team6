# 24시간 이내 고장 임박 시간 구간 모델 점검

기존 24h XGBoost Model 1은 수정하지 않았다. 실제 4초 센서 기록 82,189,440행 전체에서 각 행을 그 설비의 **다음 고유 고장 하나**에만 연결해 구간별 자료량을 집계했다. 고장 기록 1,236행의 동일 Tool·유형·시각 중복 25행은 제거해 고유 사건 1,211건을 사용했다. 각 구간의 고유 사건 수는 서로 겹친다. 예를 들어 한 고장에 0~3h와 3~6h 관측이 모두 있으면 양쪽에 한 번씩 집계된다.

| 실제 남은 시간 | 전체 원본 4초 행 | 해당 구간 관측이 있는 고유 고장 |
|---|---:|---:|
| 0~3h | 1,173,984 | 846 |
| 3~6h | 936,319 | 658 |
| 6~12h | 1,603,913 | 644 |
| 12~24h | 2,670,199 | 579 |

설비별·고장 유형별 분포는 `full_raw_by_tool_interval.csv`, `full_raw_by_fault_type_interval.csv`에 있다. 학습은 기존 Model 1의 미래 정보 없는 85개 feature를 그대로 재사용했다. 실제 1분 자료의 예측 시작 시점을 시계시간 5분 간격으로 추려 모델 규모를 조절했다. 다음 고장이 24시간 안에 있는 행만 target으로 선택하고, **fault 사건 시각과 feature 행 시각이 모두 같은 시간순 Train 또는 Validation 안에 있을 때만** 사용했다. 학습 56,546행/604사건, 검증 18,294행/218사건이다. 24시간 이상의 기존 경계 제외를 유지했고 뒤에 남긴 Test 센서는 모델에 읽지 않았다.

| 모델 | 행 기준 Macro F1 | Balanced Accuracy | 1구간 이내 정확도 | 사건 동일가중 Macro F1 | 사건 동일가중 1구간 이내 |
|---|---:|---:|---:|---:|---:|
| 가장 빈번한 구간만 출력 | 0.143 | 0.250 | 65.5% | 0.102 | 45.8% |
| HGB 균형 가중치 | **0.282** | **0.290** | **67.1%** | **0.275** | **57.7%** |

HGB의 구간별 Precision / Recall / F1은 0~3h **0.281 / 0.244 / 0.261**, 3~6h **0.221 / 0.103 / 0.140**, 6~12h **0.266 / 0.178 / 0.213**, 12~24h **0.433 / 0.636 / 0.515**다. 3~6h의 검증 2,675행 중 약 10%만 맞혔다. 가장 큰 인접 혼동은 **6~12h ↔ 12~24h 4,080행**, 이어 0~3h ↔ 3~6h 815행, 3~6h ↔ 6~12h 718행이다. 두 구간 이상 떨어진 오차도 전체의 32.9%다.

각 구간의 대표시간은 **Train 실제 TTF 중앙값만** 사용해 0~3h **1.394h**, 3~6h **4.471h**, 6~12h **8.802h**, 12~24h **17.595h**로 고정했다. Validation의 TTF는 대표시간 계산에 넣지 않았다. 네 확률과 대표시간의 가중합은 **참고시간**이지 정확한 잔여시간 회귀값이 아니다. HGB 참고시간 MAE **5.997h**, RMSE **7.175h**다. 단순 빈도 확률 기준은 MAE 6.083h, RMSE 7.004h이므로 HGB가 RMSE를 개선하지 못했다. 사건 동일가중 HGB MAE는 6.311h이다. 오차 분위수와 실제값·참고시간 산점도는 별도 파일로 저장했다.

확률은 보정되지 않았다. 검증 10구간 max-confidence ECE는 HGB **0.085**, 다중 Brier **0.755**이며 단순 빈도 기준은 각각 0.019와 0.715다. 특히 3~6h 평균 예측확률 19.5% 대 실제 비율 14.6%, 12~24h는 34.2% 대 40.1%다. 이번에는 보정기를 학습하거나 확률을 튜닝하지 않았다.

**운영 한계:** 이번 검증은 *실제 다음 고장이 24시간 안에 있다는 사실로 행을 선별*한 조건부 실험이다. 운영에서는 Model 1이 위험 경보를 내지 않은 시점에 Model 2를 보여주면 안 된다. Model 1 경보 행을 통과시켜 연결 시스템으로 측정한 성능이 아니며, 기존 Validation을 반복 사용했으므로 독립 최종 성능도 아니다. 현재 Macro F1·중간 구간 Recall·참고시간 오차·확률 보정 상태로는 **Model 2 운영 채택에 부족**하다. 다음 실험은 Model 1의 실제 경보 시점에만 이 모델을 적용해 사건 동일가중 혼동, 확률 보정, 참고시간 오차를 새 후속 기간에서 확인하는 것이다.
