# Wu-style pressure residual ablation — development-only result

**Conclusion:** This experiment does not establish useful RUL improvement from the Wu-style residual. Strict segmentation leaves 14 Train and 32 Validation windows, with just two low-pressure and one high-pressure Validation fault events; leak has none. The low-pressure matched MAE changes by only 0.20%, high-pressure by 0%, and the normal-pressure MLP has Validation R² below zero. Do not promote either GRU to Model 2 or compare these values directly with the old cross-stop baseline.

## Methods and leakage controls

- Actual 4-second sensor parquet from 20 Tools, read strictly before the frozen Validation end. Existing Model 1 and the 85-feature matrix were not loaded or modified. No fabricated measurements or shutdown filling.
- An operating segment starts at `FIXTURESHUTTERPOSITION=1` after a non-operating row, a timestamp gap above 12 seconds, non-increasing/duplicate time, a frozen split-phase change, or a crossed fault event. Each segment has Tool, start/end, observation count, elapsed time and maximum internal gap in `operating_segments.csv.gz`; rules are in `operating_segment_definition.json`. The 12-second tolerance allows at most two missed nominal 4-second ticks but is an analysis choice, not a documented Wu threshold. The 2,000-observation / 500-overlap rule creates windows wholly within one segment. The maximum actual gap among matched windows is 8 seconds.
- The Wu-style pressure MLP is separate from the RUL GRU. Its only input is **current FLOWCOOLFLOWRATE**, target is **current FLOWCOOLPRESSURE**. This exactly follows the published direction `p_hat=f(q)`, although its newly fitted weights are not the paper's. Architecture: tanh MLP widths 10/50, MSE, Adam 0.001, 8 fixed epochs. The MLP uses a deterministic 1/256 raw-row sample of Train-only, FSP=1 observations more than 24 hours from the previous and next logged fault; the full eligible population and sampled size per Tool are in `pressure_training_population.csv`. Flow/pressure standardization is fitted only on these Train samples. The Validation evaluation uses **all 8,435,147** eligible normal operating observations. Validation fault times are used only to define this retrospective normal evaluation subset, never for residual inference or scaling.
- For all finite Train/Validation operating observations, residual is `f_train(flow)-actual_pressure`. Its calculation reads no TTF, fault type or fault timestamp. Retrospective residual EDA uses a deterministic 1/64 raw-row sample and fault times only to assign analysis bins. EDA sample quantiles are therefore approximate rather than full-population quantiles.
- Set A has the exact nine raw sensor channels. Set B adds only that residual, for 10 channels. Both use exactly the same 14 Train and 32 Validation windows, the same target mask, the previous paper-baseline one-layer GRU with 32 hidden units and three heads, Adam 0.001, five epochs, log1p-hours target, and Train-only median/IQR scaling. The sole intended model-input difference is the residual channel. No existing 85 engineered inputs are used. The saved Model 1 has not been retrained.
- This is a development Validation already used elsewhere in the project. No reserved Test rows were read. An independent final score cannot be claimed.

## Segment and fault availability

There are **456,703** operating segments before the reserved Test, including 341,679 Train, 1,449 boundary-purge, and 113,575 Validation segments. Only **21 segments** contain at least 2,000 observations (13 Train, 1 purge, 7 Validation). The 20 eligible Train/Validation segments yield **14 Train + 32 Validation = 46** matched windows. The strict rule leaves three Train fault events per type, and Validation events of **2 low pressure, 1 high pressure, 0 leak**. Within-segment 2,000-observation sequences thus have too little event diversity for a meaningful RUL model comparison. The paper's FSP screening does not itself specify a 12-second gap cutoff; changing that cutoff would be a separate data-design experiment, not a feature-only ablation.

## Normal-pressure predictor and residual evidence

The Train-normal-fitted MLP obtains **MAE 0.1284, RMSE 0.5246, R² −0.0384** on eligible Validation-normal operating rows. Negative R² means that, on this population, it is worse in squared error than predicting the Validation mean; that mean is an evaluation reference, not a fitted input. These are supplied normalized pressure units, not physical pressure units. Large Tool-level residual offsets remain (`normal_residual_by_tool.csv`), so a single global flow→pressure relation is imperfect.

In the sampled EDA, low-pressure absolute residual median is **0.167** in the final 0–1h versus **0.093** when the next low-pressure fault is >24h away. However, this pooled difference is not consistent within the same events: among **233** low-pressure events having sampled observations in both 0–1h and 12–24h bins, only **111** have a larger near-fault median; the median paired change is **−0.0007**. High pressure is 13/28 with median paired change −0.0004; leak 18/30 with median paired change +0.0032. Pooled >24h bins are relative to the specified fault type and can contain another type nearby. The event-paired result and Tool offsets are more informative than the pooled difference; see `residual_event_trends.csv` and `residual_by_fault_distance.csv`.

## Matched RUL A/B results

|---|---:|---|---|---:|---:|
| Low pressure | 2 / 30 | 97.56h / 155.25h / 200.0% | 97.36h / 155.16h / 198.77% | **0.20%** | 223.33→223.19h |
| High pressure | 1 / 27 | 24.08h / 27.45h / 200.0% | 24.08h / 27.45h / 200.0% | **0%** | 24.08→24.08h |
| Leak | 0 / 0 | unavailable | unavailable | unavailable | unavailable |

Low-pressure RMSE reduction is 0.059%, SMAPE reduction 0.62%; high-pressure changes are zero. Both sets have **0% within ±1h and ±2h** on the evaluable types. R² is negative for both. Macro MAE across only the two evaluable types is 60.82h for A and 60.72h for B; it is **not** a three-type macro metric. The Train-median Dummy MAE is 496.26h for low pressure and 510.16h for high pressure on these same windows. GRU is lower than Dummy, but that comparison is dominated by target-range mismatch and very few events; it does not validate useful RUL estimation. Both GRUs produce poor absolute errors.

Only Tools `01_M01` and `03_M02` contribute Validation RUL windows. On low pressure, B differs from A by about −0.055h MAE on the one `01_M01` event and −0.215h on the one `03_M02` event; high pressure consists of one `03_M02` event. Three chronological folds cannot be meaningfully constructed from 1–2 events: `rul_fold_metrics.csv` has one score slice, not three independent forward refits. Leakage checks confirm fixed split boundaries, same A/B window IDs, max within-window gap ≤12s, and Train-only pressure and GRU scaling. No final-Test claim is made.

## Decision

The feature is **not validated as useful for RUL** here. The normal-pressure MLP fails its own Validation R² check; pooled low-pressure residual separation does not repeat consistently per event; and matched GRU improvement is negligible on only 2/1/0 Validation events. Adding Huang's reverse flow residual now would change another input while the sequence design prevents a reliable assessment. Before another feature ablation, decide and audit a gap-aware sequence policy that preserves real downtime without pretending observations on opposite sides are consecutive 4-second readings, then verify that enough distinct fault events survive in each split. Keep the current outputs as a failed/underpowered design study, not an operational Model 2.
